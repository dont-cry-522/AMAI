sounddevice 0.5.5 / PortAudio: https://python-sounddevice.readthedocs.io/
Audio input uses Windows' default microphone, 16 kHz mono PCM.
Licenses and package metadata are retained under runtime/site-packages,
including .dist-info/licenses and the bundled PortAudio license.
requirements-voice.txt lists direct Python dependencies. The complete installed
versions are recorded in the portable package's build-info.json.

The voice model and runtime are binary delivery assets, excluded from Git.
For a source-only installation, install requirements-voice.txt into the selected
Python environment, extract this model into ModelBridge/voice-model, and set
voice_enabled=true in the private local configuration. The personal portable
bundle already contains these assets and settings; its user need not install them.

No raw audio is written to disk or uploaded. Only recognized text enters the
existing configured model service, together with the team's game observations.
Offline synthetic-speech checks do not establish real-microphone accuracy.
