AMAI 模型桥接实验版 0.5（双目录）（经典版 TFT / 1.24e 优先测试）

私人一键包用户：接口、模型和密钥已配置，直接阅读《一键版说明.txt》，双击“一键开始.cmd”。
以下手动配置步骤用于源码版和排错，一键包正常使用不需要执行这些步骤。

这是供实机验证的原型，不是已经验证“更聪明”的成品。
已做：经典版脚本编译、连接程序自动检查、模拟模型接口检查、地图文件完整性检查。
已额外完成：一次指定模型的真实接口连通性及结构化回复验证。
未做：你的家庭电脑上的 Warcraft III 实机测试、对战强度测试。

适用范围
- Windows 10/11 64 位；游戏可以是 32 位。
- 单人自定义游戏：一个真人，最多三个电脑。第一轮用 2 对 2。
- 包内地图为经典海龟岛的独立副本，不需要替换原版游戏或已有地图。
- 已自带 Python 运行环境，无需安装 Python、Perl 或编辑器。
- 手机只负责携带文件，连接程序要在玩魔兽的 Windows 电脑上运行。

中文和免打字指挥（0.2 新增）
- 本包测试地图的 AMAI 台词和指挥菜单默认简体中文；模型提示词也要求中文发言。
  现有其他地图不会自动改变语言；上游少量未翻译内容仍可能回退为英文，模型输出语言也需实测。
- 开局选择“指挥模式（按ESC指挥AI盟友）”。按 Esc 打开快捷菜单，然后按一个字母或点按钮：
  F：己方电脑主力跟随我的一个存活英雄。
  W：在各自当前位置等待信号。
  A：选择进攻目标；再按列表数字或点击敌人（显示玩家名和种族）。
  R：撤回各自基地。
  C：取消手动安排，恢复 AMAI 自主行动；模型程序开启时恢复模型指挥。
  M：更多原版指令，例如单独指挥一个电脑或更改语言。此时模型暂停指挥己方。
  Esc：关闭菜单，不改变已有安排。
- 快捷菜单统一指挥己方电脑，直接在游戏内下达，不需要模型接口或外部程序。
  字母键仅在菜单打开时生效，正常操控英雄时不拦截这些字母。
- F/W/A/R 的手动命令持续生效，模型旧回复和普通聊天都不能覆盖；另一个快捷命令可替换。
  要恢复用自然语言聊天指挥，先 Esc → C。基地受威胁时仍允许 AMAI 自卫。
- 跟随与等待是两个独立命令：先 F 跟上，靠近后再 W 等待；需要出击再 A 选敌人。
- “已下达”只表示地图发出了命令，不表示军队已到位；部队响应速度仍要实机检查。
- 私人一键包新增两个地图目录：AMAI_DeepSeek 只接 DeepSeek；AMAI_DeepSeek_Voice 同时支持语音。
  两版指挥逻辑相同，共用一个连接程序。进入语音地图后才初始化语音；普通版不开启麦克风。
  语音地图中按住 F7 说话，松开提交，队友用中文文字回复。
  默认麦克风由 Windows 选择；识别在本机完成，原始录音不保存、不上传，识别文字发给现有模型。
  仅在当前魔兽程序处于前台、有实时对局数据且按住 F7 时录音。切换窗口会丢弃本次语音。
  每句限制 15 秒，超时取消；不支持语音的旧地图和未连接对局时不会录音；对局数据停止更新数秒后停止接受语音。
  屏幕上的“[你说]”显示识别结果；种族名可能识别错，模型不确定目标时应追问。
  说“恢复指挥”可以解除手动锁定。F7 如与自定义键位冲突，需要调整游戏侧键位。
  进入语音版对局后要等窗口提示“语音已准备”；依赖或麦克风异常时仍可打字及使用 Esc 菜单。
  这不是语音通话或语音播报，回复目前为游戏内中文文字。

回家操作
1. 将整个压缩包解压到本机文件夹，例如 D:\AMAI_ModelBridge_Test。不要在压缩包里直接运行。
2. 先关闭魔兽，双击 01_配置.cmd，填包含 war3.exe 的游戏文件夹路径。
   程序只复制测试地图到 Maps\AMAI_DeepSeek 和 Maps\AMAI_DeepSeek_Voice，并创建 AMAI_Bridge 通信文件夹。
   它会启用本地文件读取，并保存原注册表值；05_恢复本地读取设置.cmd 可恢复。
   不会替换 Game.dll、war3.exe 或原来的地图。请使用当前用户可写的游戏目录。
3. 先不填密钥，双击 02_通信测试.cmd，并保持窗口开启。
4. 打开魔兽，进入单人自定义游戏，打开 AMAI_DeepSeek（普通版）或 AMAI_DeepSeek_Voice（语音版）文件夹里的海龟岛。
   你和一个电脑分到一队，另外两个电脑分到另一队；先选择中等/困难电脑。
   地图文件名为 AMAI_DeepSeek_TurtleRock_v05.w3x 或 AMAI_DeepSeek_Voice_TurtleRock_v05.w3x。不要误选旧版测试地图。
   AMAI 启动选项选择“指挥模式（按ESC指挥AI盟友）”，默认已是中文。
   先关闭连接窗口，验证 Esc 菜单的 F/W/A/R/C；按 C 后再开启通信测试窗口进行下一步。
5. 等电脑造出英雄和士兵后，在聊天里依次发送以下完整词语：
   跟随测试
   等待测试
   进攻测试
   撤退测试
   自动测试
   每条之间留出约 10 秒，移动你的英雄，观察电脑主力是否跟随/停留/出击/回家。
   “进攻测试”选择槽位编号最靠前的一个敌人。
   通信测试使用固定测试词，完全不调用模型，也不是“自然语言理解”。
6. 看到“[模型指挥] 已向……下达……”只说明地图收到并下达了命令，不证明部队已完成。
   还要亲自观察行动。若只有窗口收到数据、游戏没回执，先收集诊断，不要直接开模型。

连接模型
7. 通信测试通过后，关闭测试窗口，再运行 01_配置.cmd 填入你在服务商处重新生成的密钥。
8. 双击 03_模型模式.cmd，保持窗口开启，再进测试地图。
   初版模型模式会周期性指挥双方队伍；你的聊天仅交给己方模型作为战术指令。
9. 测试：“跟着我，等我信号一起打不死族” → 移动英雄 → “上” → “撤退”。
   后续可以试“快过来帮我反打”。电脑会接收主力跟随/等待/攻击玩家、回家、自主，以及仅英雄跟随/等待/袭击三类新任务。
   “撤退”“快撤”“撤”这三个完整短句还会直接下达撤退任务并进入手动指挥，不用等模型响应。
   撤退后按 Esc → C，才恢复模型指挥。

接口预设
- OpenCode Go 模型名称：deepseek-v4.1-flash
- 接口：https://opencode.ai/zen/go/v1/chat/completions
- 官方使用说明：https://dev.opencode.ai/docs/go/#where-can-i-use-it
- 注意：OpenCode Go 当前说明要求典型编程代理流量。游戏持续决策用途没有获得官方明确支持，
  请先向服务商确认适用性。接口预填不代表已通过账户或用途验证。
- 可以改成支持 Chat Completions 的通用模型 API；换平台时，密钥也要换成对应平台的密钥。
- 不能把普通 ChatGPT 网页会员当作 API 密钥。
- 模型模式会把游戏战况和己方聊天发给配置的平台，消耗该服务额度；通信测试不联网调用模型。
- 仓库源码不含私人密钥。按你的要求，私人一键包内含本机配置，只供你本人使用，不能公开分享。
- config.local.json 含本机密钥。配置完成后不要把整个文件夹再转发，也不要上传这个文件。

当前能力和限制
- 双方按队伍分开调用模型，给模型的敌情经过视野过滤，敌方模型不会读到你的指挥聊天。
- 模型获得的是战斗单位数量、英雄数量、血量概况、位置和近期死亡事件；没有完整技能、物品和兵种评估。
- 最近 16 条发言和当前战术计划用于理解前文；讨论/追问保持任务，明确的出发信号才解除等待。
- 可以说“只带英雄跟我走，小兵留守，等我信号打不死族”→“现在上”。目标不明确时应追问。
  仅英雄袭击先去该敌人的出生点，这不是侦查确认的现有基地；全局 AMAI 视野机制未重写。
  只指挥电脑自己的英雄，不会操作你的英雄。低血量英雄、治疗、购物与基地防守优先。
  新动作已编译，但脱离主力、途中交战与保命等表现仍需实机验证。
- 模型只输出结构化指令。内容不会被当成程序代码执行。
- 跟随由电脑主力追随目标玩家的一个存活英雄，多英雄时不保证选中你正在操作的那个。
- 等待允许局部自卫；基地受威胁时 AMAI 原有防守可以优先执行。
- 模型聊天属于意图表达。是否真的到位，要看游戏内实际部队。
- 聊天消息目前显示在游戏文本区，未接入原生聊天历史；不支持敌方理解你发给它的公屏喊话。
- 原 AMAI 的经济、视野利用和难度机制没有全部改写，不能宣称整体“完全不作弊”或达到真人水平。
- 未实现精细夹击、救援优先级、兵种针对性调整、多人联机同步或永久跨局记忆。
- 模型请求约每队每 20 秒一次；真人新消息提前触发并使旧决定失效，总并发最多 3。直接回复不受闲聊冷却限制。
  语音转文字、地图轮询、模型响应均有延迟，通常需等待数秒，不是零延迟对话。
- 关闭程序/断线/回复无效后，模型控制会过期，恢复 AMAI 自主操作；并非立即停止所有部队。
  手动快捷命令由地图维持，关掉程序仍然有效，需 Esc → C 才解除。
- 只运行一个连接窗口。不要同时运行通信测试和模型模式。

有问题时
- 双击 04_导出诊断.cmd，把生成的 diagnostics.json 和你观察到的现象交给帮助你的 Agent。
- 诊断文件不包含密钥、聊天原文或电脑目录。
- 没有 state.txt：检查是否选了本包地图、游戏路径是否正确、启用本地文件读取后是否重启过游戏。
- 有 state.txt、无回执：重点检查 Preloader 本地读取兼容性和通信文件路径。
- 接口报 401/403：核对服务商、密钥、订阅权限及用途；不要把密钥发到公屏或日志里。
- 如果游戏根目录已有 Scripts 文件夹，可能存在旧 AI 覆盖冲突。不要直接删除，请先让 Agent 检查和备份。
- 模型聊天/战略表现需实测，这个版本的目的首先是证明完整通信通路可行。
